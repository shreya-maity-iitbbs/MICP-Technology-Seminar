# Overview of MICP Technology

## Project Overview

A project seminar exploring Microbially Induced Calcite Precipitation (MICP) 
technology, its underlying mechanism, and its potential applications in 
civil and environmental engineering.

## Applications Covered

- Soil stabilization
- Self-healing concrete
- Bioremediation of heavy metals

## Project Work

- Conducted a literature-based review of MICP technology and its engineering applications.
- Prepared a technical report summarizing the principles, mechanisms, and applications of MICP.
- Presented the findings as part of a project seminar.
